# New Page Skill

Use this skill when constructing a new frontend page in one of the Next.js applications.

## Instructions
1. Inquire about the target app, route, and data requirements.
2. Build page using design tokens and `packages/ui` only.
3. Configure Bengali default translations and English fallback strings in `next-intl`.
4. Include explicit loading, empty, and error fallback states.
5. Verify in browser agent at 390px and 1280px widths, and capture screenshots.
6. Run `/verify`.
